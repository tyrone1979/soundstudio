# 听审量表（大师级质量门）

配合 `runs/listening_rubric.yaml` 与 `python master_audit.py` 使用。
听审对象为审计流水线产出的 **WAV**（辅以 MIDI/MusicXML）。

## 用法

1. 跑审计：`python master_audit.py --packs mazurka fugue swing-standard --per-pack 3 --render`
2. 听 `scores/master_audit/*.wav`
3. 在报告旁的 `listening_scores.yaml`（或报告内表格）按 1–5 打分
4. 通过条件：**通用维平均 ≥ 4**，且**该包硬指标无 ≤ 2 分**

## 通用五维（每维 1–5）

| id | 名称 | 5 分锚点 | 1 分锚点 |
|---|---|---|---|
| melody_memorable | 旋律可记性 | 一句之内可哼出、有方向 | 无轮廓、碎音堆砌 |
| phrase_breath | 乐句呼吸 | 句读清晰、有起承转 | 一气灌满或莫名断句 |
| harmony_clear | 和声功能清晰 | 进行有引力、终止可感 | 堆砌或游离无功能 |
| texture_balance | 织体主次 | 主旋律明显、伴奏不抢 | 声部糊成一片 |
| genre_identity | 体裁辨识度 | 10 秒内可听出体裁 | 换成别的体裁也成立 |

## 硬指标（按包）

### `dance/mazurka`

| id | 听什么 |
|---|---|
| mazurka_accent | 重音常感到在第二或第三拍，而非每小节死拍一 |
| mazurka_dance | 有舞步感（推进/顿挫），不是匀速练习曲 |
| mazurka_piano | 钢琴语汇（织体/音区）可信，不像弦乐垫写 |

### `academic/fugue`

| id | 听什么 |
|---|---|
| fugue_subject | 主题可辨、再次进入听得出来 |
| fugue_answer | 答题/模仿关系清楚，不是齐奏假复调 |
| fugue_independence | 声部独立运动，不长期同节奏撞车 |

### `jazz/swing-standard`

| id | 听什么 |
|---|---|
| jazz_walking | 低音有走动感（四分脉搏），不是长音垫 |
| jazz_comping | 伴奏有 2&4 / 切分柱式空间，不是古典琶音 |
| jazz_harmony | 七和弦/ii–V 色彩可感，不是三和弦进行 |

## 与符号门的关系

| 层 | 自动？ | 作用 |
|---|---|---|
| 风格命中 top3 / 属性遵循 / 语料 NN | 是 | 挡「不像该包」与「抄语料」 |
| 本量表 | **人工** | 挡「统计像但难听」 |

符号全过 + 听审不过 → 改内核/契约，不扩空包。
