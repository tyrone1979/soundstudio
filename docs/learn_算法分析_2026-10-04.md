## 三、已修复的确定性缺陷

### 3.1 R03/R04 矛盾

`forbidden = range(5, max_leap)`（开区间），不再把 `max_leap` 本身列入禁用。  
`compose.py` / `check.py` 读的是 `melody.max_leap` / `forbidden_leaps` 字段，规则文本会随之一致。

### 3.2 `first_chord` 守卫

```python
firsts = []
for p in mt:
    ev = harmony_events(p, vset)
    if ev:
        firsts.append(ev[0][3])
```

### 3.3 `openings` 边界

`len(f) >= n`，恰好 n 段的曲子计入「前 n 段」分布。

### 3.4 剪枝回归 + 共享 k-means

见 `learn_core.prune_with_regression` / `kmeans(..., n_init=10)`。  
evaluation 中新增 `prune_kept`（是否保留了剪枝结果）。

## 四、原评估信号（仍有效，作背景）

留出困惑度表（剪枝前基线）显示多数 style 上盲目剪枝有害——这正是本轮加回归回退的动机。  
`hardbop/minor` 曾输给 unigram：回退后至少不会比 unpruned 更差；若仍差于 unigram，属数据/词表问题，需另开任务。

**术语**：

- `bigram_coverage`：转移对在训练 L1 中 attested 的比例（chorale 原有；leadsheet 已对齐）
- `coverage`（leadsheet）：词表召回（单个和弦 in vocab）——与上者不同，勿混用
