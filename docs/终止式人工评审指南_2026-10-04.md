**评审对象**：`cadence_audit.json` 中 35 条「其他终止」规则（287 条里规则表自动解决 0 条、剩下的就是这 35 条）。
**你只需要两个文件**：

| 文件 | 用途 |
|---|---|

| `docs/cadence_review/终止式评审表.xlsx` | **评审表**。「填写说明」一页看完；「评审表」35 行，每行一条规则，下拉框打分；「谱例索引」85 次出现的定位。 |

（可编辑源谱：`docs/cadence_review/终止式评审乐谱.musicxml`，MuseScore / Finale 可打开。）

## 一、看谱

每个谱例的标题行已经把关键信息写全：

```
【C105 · 第1/3次】 ii – ii⁶ – vi
bwv355 · A大调 · 4/4 · 第3/8句 · 第5–6小节 ｜ 女高音终止音 5→4
```

- **终止窗口** = 末尾 3 个和弦，低音谱下方标了罗马数字（ii / ii⁶ / vi）；
- 带**延长记号**的音就是句尾（本数据集的「乐句」由女高音延长记号定义，不是教科书乐句分析）；
- 女高音落音的数字是**相对主音的音级**（1=主音、5=属音），只到音级、**不含八度**。

## 二、打分（评审表每行 7 个下拉列）

| 列 | 填什么 |
|---|---|
| ① 是否真实终止位置 | `REAL_CADENCE` / `SUSPECT-低·中·高` / `NOT_CADENCE`（三拍同和弦、延长记号误读等） |
| ② 终止式类型判定 | `RECODE_PAC/IAC/PC/HC/DC/SECONDARY/TONIC`＝改判；`KEEP_OTHER`＝确认"其他终止"没错；`MODULATED`＝转调（备注写新调）；`NOT_CADENCE` / `UNDETERMINED` |
| ③④⑤ 等级 | 正确 / 部分正确 / 错误 / 无法判定。**⑤ 位置一栏没有「正确」**——数据里本来就没有位置标注，只能对照先验 |
| 置信度 | 高 / 中 / 低 |
| 判定依据 | **必须引用谱面事实**（如「低音 6→4→3 下行、女高音落 3」），"听起来像"无效 |

**「正确」的三个准入条件**（不满足最高只能给「部分正确」）：
1. 结论不依赖女高音八度（判 PAC/IAC 必须有原谱音高）；
2. 结论不依赖乐句在曲中的位置；
3. `n ≥ 3`，或该模式本身无歧义。

## 三、四个最常见的坑（先记住这四条，80% 的判定不会错）

1. **转调**：小调终止在 **III**（关系大调主和弦）的 10 条（C217–C233）——大概率是转到关系大调的终止，判 `MODULATED` 并在备注写新调。
2. **副属悬空**：终止在 **V/ii、V/vi** 上而目标 ii/vi 没出现的 7 条（C133–C139）——既不是正格也不是离调终止，判 `KEEP_OTHER` 并备注「副属悬空」。
3. **属七结尾**：判定程序只认大三和弦的属，属七结尾全掉进「其他」——属七结尾**可以**判半终止 `HC`（C287）。
4. **样本太薄**：25 条只有 `n=2`，最高只能给「部分正确」。

其他：三拍同和弦（C230、C261）按 `SUSPECT-高` 处理；升降号拼写不可信，以音级为准。

## 四、一致性锚对（判定必须自洽）

| 锚对 | 差异 | 要求 |
|---|---|---|
| C105 ↔ C135 | 仅末和弦不同（vi vs V/ii） | 若同判某类型则至少一个错，须写明区别 |
| C139 ↔ C140 | 仅末和弦性质不同（V/vi vs iii） | 同上 |
| C217 ↔ C221 | 和弦全同、仅女高音不同 | **必须同类型** |
| C224 ↔ C232 | 和弦全同、仅女高音不同 | 同上 |

## 五、多人不一致怎么办

1. **先归一**：PAC/IAC 同属正格族、PC/主和弦终止同属变格族——同族内的分歧取**约束更松**者，记入备注，不仲裁。
2. **跨族分歧**（如 HC vs NOT_CADENCE）：两人复议；仍不一致交第三人（有和声背景）仲裁。
3. **仲裁优先级**：D0/D4 否决 > 有原谱证据者 > 触发上述四条坑的一方 > 保守结论 > 仲裁人终裁（须写理由，保留两人原始结论）。
4. **盲评**：第一轮互不看对方结果；评审期间冻结 `grammar.yaml`（更新会导致 C 编号变化）。

## 六、交付

填好的 `终止式评审表.xlsx`：35 行每行必填，「判定依据」不得留空；`需补谱例?=是` 的条目单独列出（这些需要工程方导出原谱上下文后二次评审）。
