# 各风格提示词大全

只用**已学且证据充足**（≥24 首大师级语料）的风格包。
未达门槛的专家包已下线；不要用四重奏等代理语料冒充小夜曲。

`/style` 用法：写**正式中文名** + 创作描述：

```text
/style 摇摆标准曲（爵士） 写一首Bb大调，中速摇摆
/style 英伦爱尔兰曲调 里尔舞曲，D大调
```

## 怎么用

1. Studio / CLI 直接输入下方**推荐短句**（≤220 字更易触发扩写）。
2. 想指定调性：写清「G 大调」「D minor」等。
3. 交响类短句会先经 `brief_expand` 扩成专业分段 brief。
4. 同一短句默认结果相近；要变奏可改调性/情绪词，或换 seed。
