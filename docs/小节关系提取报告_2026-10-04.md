## 二、层级结构（三级）

```
段落 FORM（曲式段）→ 乐句 PHRASE → 小节 BAR
```

节点 ID 格式（全局唯一，可直接回溯）：

| 层级 | ID 格式 | 例|
|---|---|---|
| 段落 | `{melid}-seg[A2]` | `0007-seg[A2]` |
| 乐句 | `{melid}-ph{no}` | `0007-ph6` |
| 小节 | `{melid}-b{nnn}` | `0007-b042` |

**归属规则**：PHRASE 标注会跨 FORM 边界，因此按**中点归属**唯一分配给一个段落，
避免同一乐句被挂到两个父节点下。原始跨越信息保留在 `form_mix` 字段。

## 三、样例：0007 — I Got It Bad（Benny Carter, SWING, 49小节）

曲式：`A1 A2 B1 A3 B2 A4` —— 典型 32 小节 AABA'

### 层级与主题

```
A1  [小节 2-9]
  └ 乐句1[小节 2-2]   主题引用(t1)
  └ 乐句2  [小节 3-3]   主题引用(t2)
  └ 乐句3  [小节 4-5]   主题引用(t3-4)
  └ 乐句4  [小节 6-8]   主题引用(t5-7)、Bebop 线
  └ 乐句5  [小节 8-9]   Bebop 线
A2  [小节 10-17]      ← 同一 A 材料的第一变体
  └ 乐句6  [小节 10-10] 主题引用(t1)        ← 与 A1 乐句1 同一主题
  └ 乐句7  [小节 11-12] 即兴乐句·变形、cx 线
  └ 乐句10 [小节 16-17] 主题线
B1  [小节 18-25]      ← 对比段
  └ 乐句12 [小节 18-19] 主题引用(t17-18)
  └ 乐句13 [小节 20-21] Bebop 线
A3  [小节 26-33]
A4  [小节 42-49]
```

`主题引用(t1)` → `主题引用(t5-7)` 的递进，**精确复现了 AABA' 的主题陈述结构**。

## 四、小节主题的构成

每个小节的主题由三部分组成（`bars[i].theme`）：

| 字段 | 来源 | 例|
|---|---|---|
| `form_label` | FORM 段标签 | `A2` |
| `form_family` / `form_index` | 字母族 / 序号 | `A` / `2` |
| `idea_themes` | IDEA 词归类 | `['主题引用(t1)']`、`['Bebop 线·变形']` |
| `chorus` | CHORUS 标注 | 副歌标记 |

**IDEA 词表 615 种**，已归类 97.7%（未归类仅 2.3% / 356 条）。归类规则：
剥 `#~*+-` 修饰前缀 → 剥编号前缀（`#7lick` → `lick`）→ 最长前缀匹配。

主要主题类（按小节出现次数）：

```
即兴乐句 10,738   Bebop 线 9,785   即兴乐句·装饰 3,760   旋律陈述 1,836
即兴乐句·变形 1,384   Bebop 线·变形 872   自由表情 679   留白→起句 554
```

其中 `主题引用(tN)` 与 `动机引用` 是**有明确指向的主题标签**，
可直接用于「小节引用了哪个主题」这类查询。

## 五、无法确定关系的小节

**659 个小节（1.9%）标注为 `unclear`**，全部因为不在任何 FORM 段范围内
（前导、间奏、尾声的即兴段）。这些小节：

- 层级归属不可判定（不属于任何段落）
- 横向关系不可判定（无 form_label 可供对比/引用）
- 但**保留了小节 ID 与位置**，可人工追补

报告中每首曲目末尾都会列出这些小节的具体区间。

## 六、索引语义（关键，务必记录）

`sections.start/end` **不是** `melody.eventid`，也**不是** `melody.bar`，
而是**该 melid 内按 eventid 排序后的 0-based 行偏移**。

误判会**静默返回空结果**：

| 假设 | 实测 | 判定 |
|---|---|---|
| `= eventid` | melid=3 的 eventid 范围 1197-1569，标注 0-372 → 越界，可用 **0** 首 | ❌ |
| `= bar` | 标注跨度 130 vs `bar` 最大 129 → 巧合接近 | ❌ |
| **`= 行偏移`** | melid=1 标注 0-529，melody 530 行 → 吻合 | ✅ |

正确映射（已固化为测试用例）：

```python
rows = list(conn.execute(
    'select eventid, bar from melody where melid=? order by eventid', (mid,)))
bs = rows[start][1]      # 行偏移 → bar 号
```

## 七、已知数据缺陷

1. **`sources.py:695` `_MAX_EXPORT_BARS = 32`** —— 导出 lead sheet 时硬截断到
   32 小节。实测 jazz cache 里209/410 首（51%）恰好 32 小节，
   而 FORM 标注常延伸到 130 小节。**本提取器不依赖 cache，直接读 db 的
   `melody` 表，因此不受此影响**；但若要用 cache 的和声特征，需先放开该上限。
2. **PHRASE 可能越过最后一个小节**（收尾音符），已钳到合法范围并标 `clamped`。
3. **`grammar_cache` 的 `phrases` 是启发式**（`grammar/analyze.py:141-171`
   按延长记号判定），且 `phrases_inferred` 标志在 cache 里 350/350 全为 `None`，
   **不可当真值**。本报告用的是 db 的 PHRASE 人工标注。
