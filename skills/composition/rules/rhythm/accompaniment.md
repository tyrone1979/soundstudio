# 伴奏织体型

## 常用型

| 型 | 特征 | 适用 |
|----|------|------|
| 根音 / 低音 | 每拍或每小节根音 | 简单支撑 |
| 柱式和弦 | 同时响和弦音 | 众赞、进行曲 |
| 分解 / 阿尔贝蒂 | 低-高-中-高 等 | 古典钢琴 |
| 节奏型重复 | 固定节奏细胞 | 流行、舞曲 |

## 系统路径

- 编辑器：**添加声部** + **配乐**（`music_score/part_accomp.py`）。
- 内核：`accompaniment(pattern=…)`；须在 melody 之后、narrative/finalize 之前按调用序。
- 对位任务：第二声部是对位声部，不是「配乐」；勿对 CF 乱套阿尔贝蒂。

## 原则

1. 伴奏勿盖过主旋律音区与节奏焦点。
2. 和声节奏可慢于旋律（一和弦多拍）。
3. 句末可简化织体以配合终止。
