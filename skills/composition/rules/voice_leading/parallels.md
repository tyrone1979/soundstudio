# 平行五度 / 八度

## 定义

两声部在相邻两个和弦（或两个对位音）上**同时换音**，且两音程均为**纯五度**或均为**纯八度/同度**，即构成平行五/八度。

## 教学态度

| 体裁 | 态度 |
|------|------|
| 众赞 / 严格四部 | 严禁（任意声部对） |
| 对位法第一类 | 中间可用 5/8，但起止与运动仍受对位条文约束；连续平行仍不推荐 |
| 管弦 / 钢琴织体 | 外声部慎用；内声部偶发可接受 |

## 检测与修复

- 编辑器 / `score_studio`：平行检测与提示。
- `finalize`：可对外声部平行做自动修正（非 preserve 模式）。
- 对位校验器：以音程集合与运动规则为主，不单独替代 SATB 平行扫描。

## 写作建议

- 换和弦时至少一声部级进或反向。
- 避免两外声部同向跳进落在五/八度。
- 若必须保持五度色彩，改用斜向（一声部静止）或错开节奏。
