# 乐句和声模型（T → PD → D）

来源：[Open Music Theory — Introduction to Harmony, Cadences, and Phrase Endings](https://viva.pressbooks.pub/openmusictheory/chapter/intro-to-harmony/)。

## 功能链

古典乐句内部典型顺序：

1. **T（主功能）**：I（偶有 iii）建立调性。
2. **PD（下属预备）**：ii / IV（偶有 vi）离开主、准备属。
3. **D（属功能）**：V / V7 / vii° 导向终止。

完整乐句常以 **T–PD–D–（T）** 收束；半终止停在 D。

## 写作约束（教学级）

- 乐句中途一般**不**作功能倒退（如 D 后再大段 PD 而无理由）。
- 同一功能内可换和弦（I–vi–I、ii–IV 等），但要保持方向感。
- 规划小节时：起句稳主 → 中段 PD → 末拍/末小节 D 或完整 PAC。

## 在本系统中的用法

- Planner / `harmony` 脚本应按功能链排布罗马数字，再交给 `melody` / `accompaniment`。
- 对位法任务**不**用罗马数字链约束中间音程（仍用 3/6 为主规则）。
