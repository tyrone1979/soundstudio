# 常用和弦进行

综合 musictheory.net 进行课与本仓库 `chord_advisor` / 风格骨架。

## 教学常用套路

| 名称 | 级数（大调示例） | 备注 |
|------|------------------|------|
| 正格 | I–V–I / I–IV–V–I | 基础收束 |
| 变格感 | I–IV–I | 赞美诗/民谣感 |
| 下行四度圈 | I–IV–vii°–iii–vi–ii–V–I | 圈进行片段常用 |
| ii–V–I | ii–V–I / ii7–V7–I | 爵士与古典共通 |
| 流行 I–V–vi–IV | I–V–vi–IV | 流行歌谣 |
| 古典 I–vi–IV–V | I–vi–IV–V | 常见前句材料 |

## 小调注意

- 属功能常用 V 或 V7（含导音），自然小调 v→i 较弱。
- 和声小调升 VII；旋律小调上行升 VI+VII。
