# 非和声音（经过 / 邻音 / 留音等）

来源概要：musictheory.net「Nonharmonic Tones」课系。

## 常见类型

| 类型 | 特征 | 拍位倾向 |
|------|------|----------|
| 经过音 PT | 两和弦音之间级进填空 | 常弱拍 |
| 邻音 NT | 离开和弦音再返回 | 常弱拍 |
| 留音 Sus | 前和弦音延留后级进解决 | 强拍不协和→解决 |
| 倚音 App | 跳进进入不协和再级进解决 | 常强拍 |
| 先现 Anticipation | 后和弦音提前出现 | 弱拍 |
| 逃音 Escape | 级进离开、跳进进入下一和弦音 | 弱拍 |

## 写作原则

1. 强拍优先 prioritise 和弦音（尤其教学作业与众赞）。
2. 不协和需解决：留音/倚音级进解决；七度按倾向解决。
3. 对位第一类**不写**非和声音（严格 1:1 协和音程）；第二类及以后才引入节奏错位与经过。

## 系统

- `_s_melody` 可在和弦框架上加经过/邻音式装饰（由风格与强度参数调节）。
- 严格对位路径关闭此类装饰。
