# 旋律轮廓与动机发展

## 轮廓

- **级进为主**，跳进为点缀；大跳后反向级进「回收」。
- 避免无方向连续大跳；高潮常靠近黄金分割或乐句末前。
- 起音与落音关系影响收束感（落主音更强）。

## 动机手法

| 手法 | 说明 |
|------|------|
| 重复 | 原样或轻微节奏变 |
| 模进 | 移调重复 |
| 倒影 | 音程方向翻转 |
| 逆行 | 时间倒序 |
| 增时 / 减时 | 时值拉长 / 压缩 |
| 加花 | 填充经过音 |

## 系统

- `_s_melody`：按和声写主旋律轮廓。
- `_s_narrative`：可用动机变形出场（倒影/逆行/增时等）；明确「不要赋格/模仿」时应关 `appearances`。
- 对位 CF 提取后，对位声部按对位规则写，不按动机变形脚本乱改 CF。
