# 乐谱分析建议生成器

## 何时使用
- 用户上传 MusicXML 文件并要求分析
- 用户询问“这首曲子有什么问题”“如何让乐谱更丰富”
- 用户需要针对声部运用、调性、节奏的改进建议
- 命令 `/advice`

## 步骤

1. **解析乐谱**：运行 `scripts/parse_score.py` 提取声部、音符、节奏、调性信息
2. **逐项检测**：对照 `references/checklist.md` 中的检测规则，识别问题
3. **生成建议**：按优先级排序，给出具体小节和可操作的修改方向
4. **避免误判**：如果某条规则不适用（如极简风格 intentionally 使用长音），在输出中注明

## 核心检测维度

### 声部运用
- 长音占比 > 0.8 的声部 → 标记“声部浪费”
- 某声部从第 1 小节到最后全是长音 → 标记“角色单一”

### 调性变化
- 调号全曲未变 且 无离调和弦 → 标记“缺乏调性对比”
- 建议：在 [第 X 小节] 可转向 [属调/关系小调]

### 节奏多样性
- 连续 4 小节节奏密度完全一致 → 标记“节奏单调”
- 每 4 小节至少应出现一次：附点、切分、三连音、十六分音符

### 动机发展
- 使用本地动机扫描检测重复动机
- 同一动机原样出现超过 2 次 → 标记“缺乏模进/变形”

## 输出格式

按优先级排序（🔴高 / 🟡中 / 🟢低），每条包含：
- **问题**：一句话描述
- **位置**：具体小节/声部
- **修改方向**：可操作的建议

## 边界
- 不自动修改乐谱文件，只输出建议
- 用户确认后（「可以」「执行」或 `/apply`）才进入整曲改写
- 如果用户要求具体音符级改写方案，才进入下一阶段
