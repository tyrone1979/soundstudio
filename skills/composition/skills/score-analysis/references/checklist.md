# 乐谱改进检测清单（score-analysis）

对照当前乐谱事实（`parse_score` 输出）逐项检查。风格上 intentional 的简化（极简、圣咏长音等）应标注「可能不适用」而非硬报错。

## 🔴 高优先级

### H0 外声部平行五度
- **触发**：最高旋律声部与低音声部同向进行，且换音前后音程均为纯五度（平行八度作为加强通常可接受，不硬报）
- **输出**：指出拍点/小节与两声部音级；建议改低音反向/斜向，或改内声填三度六度，消除平行五度

### H1 声部浪费 / 角色单一
- **触发**：某声部长音（ql≥2）占比 > 0.8；或从第 1 小节到末尾几乎只有二分/全音符
- **输出**：指出声部名；建议在展开段接旋律、与主旋律形成平行三度/六度、或做短动机呼应

### H2 缺乏调性对比
- **触发**：全曲调号不变，且无明显离调和弦 / 临时变音簇
- **输出**：建议在曲式中段（约 40%–60% 处）转向属调或关系小调；给出具体小节区间

### H3 和声节奏死板
- **触发**：某一伴奏/圆号类声部几乎每小节一个柱式和弦且节奏均匀
- **输出**：终止式前加快和声节奏；展开段可放慢为两小节一换

## 🟡 中优先级

### M1 旋律节奏单调
- **触发**：旋律声部连续 ≥4 小节节奏密度完全一致（如全是八分）
- **输出**：每 4 小节至少引入一次附点、切分、三连音或十六分

### M2 动机原样重复过多
- **触发**：同一音高轮廓动机原样出现 > 2 次
- **输出**：建议模进、节奏变形或倒影，并指出应改的小节

### M3 弦乐/低音只做铺底
- **触发**：弦乐组几乎全是长音，无分解、对位或终止推进
- **输出**：中段分解和弦；终止前短促和弦推进

### M4 铜管进入突兀或只奏长音
- **触发**：小号等大量休止，进入时仅长音和弦、无号角动机
- **输出**：短附点号角动机或与圆号呼应

## 🟢 低优先级

### L1 力度缺失
- 全曲无 dynamics → 建议句首/高潮/收束标记

### L2 演奏法缺失
- 无连音线 / 断奏 / 重音 → 给旋律加 slur，长音区可 arco/pizz 交替

### L3 曲式过度对称
- 每 4 小节一句且无对比段织体变化 → 建议中段织体变薄、调性偏离后再强势回归

## 输出时注意
- 每条必须有：问题 / 位置（小节+声部）/ 修改方向
- 最多列 8–10 条，优先 🔴
- 不改谱，只建议
