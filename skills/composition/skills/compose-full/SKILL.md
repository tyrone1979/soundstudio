# 整曲创作

无选区时从零生成完整短曲。当前主路径是 **翻译器 → 确定性内核**：
LLM 只输出对 `compose_kernel` 脚本的调用序列（不写音符），音符由内核生成并
保证时值 / 调性 / 织体 / 力度 / 终止正确。

本文件通过 `index.yaml` 的 `inject: [translator]` 注入翻译器提示词；
旧路径的 composer 提示词里另有一份英文同文（`base/composer.md`）。

## Gotchas — 防止旋律单调的硬性规则

以下规则在写谱阶段强制遵守（翻译器据此安排段落与脚本参数）：

- **禁止连续 4 小节使用相同的节奏密度。** 每 4 小节必须出现至少一种：附点、切分、三连音、十六分音符。
- **每个乐句至少包含一个四度以上跳进**，且跳进后必须反向级进解决。
- **主题动机每次出现必须变形**：模进到不同音级、改变节奏、或倒影。禁止原样重复超过两次。
- **和声节奏不得全程每小节一换。** 在终止式前允许加速，在展开段允许放慢。
- **每个声部必须有至少 4 小节担任旋律或对位角色**，不得全程只奏长音。
- **全曲必须至少有一次调性偏离**（转调或离调），不得从头到尾停留在主调。
- **外声部（最高旋律 vs 低音）禁止同向平行纯五度。** 优先反向/斜向，或三度/六度；故意八度加强可以，失控平行五度不行。

## 落到脚本上的对照

| 规则 | 翻译器怎么做 |
|---|---|
| 节奏密度变化 | 同一曲内混用 `melody(rhythm=sparse/flowing/fragmented/driving)`，不要全曲都写 flowing |
| 跳进 + 反向解决 | 给 `melody(motif=[[级数1-7,时值名],…])`，让内核按动机做二度模进 |
| 动机变形 | 复用同一 `seed` 并换 `melody(motif=…)`，或改 `contour` |
| 和声节奏 | `set_harmony(progression=…)` 的循环长度不要恒等于段长 |
| 声部角色 | `accompaniment(pattern=…)` 避免全曲同一个 pattern |
| 调性偏离 | 某段用 `set_harmony(key_sharps=…, mode=…)` 做段落级转调 |
| 平行五度 | `finalize` 自动规避，无需手工处理 |

反例（应避免）：整段只有「上上下下」的级进波浪、副声部全程长音铺底、从不离调、动机原样反复、外声部齐步平行五度。
