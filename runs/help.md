# ComposerChat 帮助文档（确定性内核 · 规则校验 · 可复现 · 可审计）

> 所有命令与功能都建立在确定性内核之上：**零训练数据、seed 固定可复现、规则校验、可审计**。带示例，复制即可用。

## 一、功能清单（每个功能一个示例）

### ▸ 核心能力

- **自然语言作曲** — 用自然语言描述想要的曲子，自动匹配风格包并生成符号谱（MusicXML/MIDI）。
  - 相关命令：`（自然语言输入）`、`/style`、`/new`
  - 示例：`做一首雨夜钢琴风格的圆舞曲，带一点忧伤`
  - 效果：匹配「雨夜钢琴」风格包，生成 3/4 拍、柔和哀婉的圆舞曲。

- **风格包与绑定** — 风格包是护城河基石：零训练数据的确定性指纹。/style 设定基调并可绑定 genre 包，创作描述单独记录。
  - 相关命令：`/style`
  - 示例：`/style 圆舞曲 快板轻盈`
  - 效果：绑定圆舞曲风格包，并把「快板轻盈」作为创作描述传给生成器。

### ▸ 增强功能

- **风格插值 / 参数化风格合成** — 在两个风格之间确定性插值，得到「二者之间」的新风格——参数化风格合成，可复现、不调 LLM。
  - 相关命令：`/interpolate`
  - 示例：`/interpolate 雨夜钢琴 圆舞曲 40%`
  - 效果：在雨夜钢琴与圆舞曲间按 0.4 权重生成过渡风格乐曲。

### ▸ 核心能力

- **赋格与对位** — 内置赋格引擎：仅当 brief 明确提到赋格/卡农/创意曲时写入赋格段，或整首写成赋格（主题-答题-展开）。普通对位提示不会自动加赋格。
  - 相关命令：`/fugue`
  - 示例：`/fugue full`
  - 效果：整首按赋格写法生成（二声部时为二声部创意曲）。

- **确定性骨架** — 不调 LLM 的纯确定性骨架：按风格包指纹直接铺节奏/和声骨架，可复现可审计。
  - 相关命令：`/skeleton`
  - 示例：`/skeleton 圆舞曲`
  - 效果：确定性生成圆舞曲骨架，seed 固定时结果完全可复现。

### ▸ 增强功能

- **Groove 人性化后处理** — 导出/回放 MIDI 时做确定性人性化：力度微扰 + 微量 timing + swing，落在表演层，不改符号谱正确性。
  - 相关命令：`/groove`
  - 示例：`/groove on 0.2 0.5（然后 /export）`
  - 效果：回放更有「人味」，且因 seed 固定而可复现。

- **风格保真度闭环精炼** — 确定性 DPO 等价物：锁 seed、用 seed 分支与旋钮坐标上升最大化风格重叠率，输出可审计的精炼谱。
  - 相关命令：`/refine`
  - 示例：`/refine 赋格`
  - 效果：在风格指纹上收敛到高保真版本，并给出每一轮 overlap 的审计轨迹。

- **MusicXML 往返导入** — 对标 AIVA 的 DAW 编辑闭环：导入外部（含 DAW 改过的）MusicXML，用规则引擎复检并重新规范化导出。
  - 相关命令：`/import`
  - 示例：`/import /path/to/song.musicxml`
  - 效果：校验时值完整性/声部引导/音域/风格重叠，并重导出规范文件。

### ▸ 核心能力

- **五线谱记谱符号** — 谱面显示与 MusicXML 导入/导出共用同一套记谱模型，以下符号均可显示且往返不丢：谱号（高音/低音/中音/次中音/高音8vb/低音8vb，可曲中换谱号）、调号（含换调还原号）、拍号（数字或 C/¢，可曲中换拍）、符杠（含次级符杠）、延音线（可跨小节/跨行）、圆滑线（可嵌套）、三连音等连音（括号+数字）、倚音、演奏法（跳音/短跳音/重音/强重音/保持音/延长记号）、装饰音（颤音/波音/逆波音/回音）、琶音、换气记号、力度（小节首与小节中途）与渐强/渐弱楔形、速度（文字 + ♩=数值）、文字指示、排练号、歌词、和弦记号、双纵线/终止线/虚线小节线、反复记号与房子号、弱起小节；调内变音按调号与小节内已出现的升降自动省略/补还原号，重升/重降用矢量绘制。
  - 相关命令：`/import`、`/export`
  - 示例：`/import scores/chopin_mazurka.xml`
  - 效果：三连音、换调、反复等按原谱显示；编辑后导出再导入与原谱逐音一致。

### ▸ 增强功能

- **乐谱逆向复现** — MusicXML→纯中文逐音文字描述→MusicXML（无 JSON）；/replay 按文字还原，音符级一致，不调 LLM。
  - 相关命令：`/reverse-prompt`、`/replay`
  - 示例：`/reverse-prompt
/replay`
  - 效果：产出 score_description.md；复现后与源谱音符级一致。

- **简单提示词扩写** — 把「写一首明朗的交响曲快板乐章」等短句确定性扩成专业分段 brief；创曲路径自动触发，也可用 /brief-expand 只看扩写结果。
  - 相关命令：`/brief-expand`
  - 示例：`/brief-expand 写一首明朗的交响曲快板乐章，像舒伯特早期`
  - 效果：输出含编制、速度阶梯、段落对比的可执行专业提示词。

- **和弦进行顾问** — 对标 Hooktheory / Captain Chords 的交互式和弦顾问：纯和声逻辑、零依赖、不调 LLM；调内合法性 + 功能圈 + 导音解决 + 四声部 + 平行复检。加 write 可写入钢琴大谱表。
  - 相关命令：`/chords`、`/satb`
  - 示例：`/chords I V vi IV
/satb I V vi IV`
  - 效果：对进行做校验、功能分析、SATB 实现并检测平行五八度；/satb 直接生成钢琴大谱表四部和声。

### ▸ 核心能力

- **规则库（作曲库管理器）** — 作曲库「规则库」页统一管理对位权威、和声/声部/乐句教学规则与全部确定性内核脚本；每条可同时查看文档与实现源码。菜单：作曲库 → 规则库。规则摘要会自动注入 Planner/Translator 提示词，供 LLM 按意图选字段与脚本。
  - 相关命令：`作曲库管理器（Ctrl+L）→ 规则库`
  - 示例：`打开作曲库管理器 → 规则库 → 第一类二声部对位 / 终止式 / 脚本 melody`
  - 效果：左侧按分类浏览规则；右侧文档 + 代码双栏；创曲时摘要进入 Planner/Translator。

### ▸ 增强功能

- **钢琴大谱表四部和声** — 在钢琴大谱表（RH/LH 花括号）上写四部和声：S+A 叠写高音谱表，T+B 叠写低音谱表；菜单「新建钢琴四部和声谱」或 /satb。
  - 相关命令：`/satb`、`/chords`
  - 示例：`/satb Bb I IV V I`
  - 效果：打开可编辑的钢琴大谱表，每小节一个和弦的四声部。

- **二声部对位（钢琴大谱表）** — 第一类二声部对位（对位法权威规则）：Planner 识别后确定性写谱并校验。凡涉及对位/一比一/species 均套用同一规则集（禁纯4、禁同时跳进、限平行3/6、反向为主、终止导→主/Ⅱ↓Ⅰ等）。对位≠赋格。也可「根据当前打开的乐谱写一个1比1对位」：抽定旋律再写另一声。
  - 相关命令：`/help`
  - 示例：`根据当前打开的乐谱写一个1比1对位`
  - 效果：从当前乐谱每小节抽一音作定旋律，生成钢琴大谱表二声部 1:1 对位；无当前谱时也可从零写「2声部一比一对位」。

- **MIDI 键盘输入** — 接入外部 MIDI 键盘步进输入（macOS CoreMIDI / Windows MM，基于 mido+python-rtmidi）。按下的键实时以橙色显示在五线谱上；默认左右手分谱：分手点（默认 C4）及以上进右手高音谱表、以下进左手低音谱表，单谱表时自动升为钢琴大谱表；两手同时按的和弦各自写成和弦并上下对齐，只弹一只手时另一只手补休止。可选和弦模式、八度偏移、分手点。
  - 相关命令：
  - 示例：`工具 → MIDI 键盘 → 启用 MIDI 输入；左手按 C3+G3、右手按 C5+E5+G5`
  - 效果：按住时谱面出现橙色预览；写入后右手得到 C5-E5-G5 和弦、左手得到 C3-G3 和弦，同一拍对齐。

- **渲染增强（soundfont/混响/力度）** — 对标 AIVA 渲染管线的确定性渲染层：SoundFont 音色选择 + 卷积混响 + 力度曲线。全部落在表演层，不改符号谱音高/时值/和声；同输入逐样本可复现、可审计。
  - 相关命令：`/render`
  - 示例：`/render piano reverb 0.3 velocity soft`
  - 效果：用 Salamander 钢琴采样 + 30% 混响 + 柔和力度，渲染当前乐谱为 WAV。

- **风格包批量生成流水线** — 复用确定性内核的批量产出：枚举风格包→每包生成 N 首确定性骨架乐谱（MusicXML+MIDI）→ 算风格保真度 → 出审计报告。不调 LLM、可复现。
  - 相关命令：`/batch`
  - 示例：`/batch fugue chorale`
  - 效果：为 fugue、chorale 各生成 1 首确定性乐谱，并产出 runs/batch_report.md/.csv。

### ▸ 核心能力

- **五线谱辅助编辑教程** — 空谱点写 + 程序化补全 + LLM 听审：从零手写出莫扎特《小夜曲》开篇完整 16 小节。
  - 相关命令：`/assist`、`/key`、`/tempo`、`/meter`、`/bars`、`/new`、`/export`
  - 示例：`/help 编辑教程`
  - 效果：打开完整教程：准备空谱 → 手写动机/应答/收束 → 辅助预览与听审 → 播放导出。

- **编辑指令族** — 一整套规则驱动的改谱指令：续写/扩展/发展/变奏/配器/移调/裁剪/简化/复杂化/重写。均在已有乐谱上确定性改写。
  - 相关命令：`/continue`、`/extend`、`/develop`、`/variation`、`/orchestrate`、`/transpose`、`/shorter`、`/longer`、`/simplify`、`/complexify`、`/rewrite`
  - 示例：`/extend 8 然后 /transpose D`
  - 效果：先把乐曲延展 8 小节，再整体移调到 D。

- **分析与建议闭环** — 先 /analyze 看特征与风格重叠，再 /advice 拿建议，确认后 /apply 改谱——规则驱动、无幻觉。
  - 相关命令：`/analyze`、`/advice`、`/apply`
  - 示例：`/analyze → /advice → /apply`
  - 效果：形成「看数据 → 出建议 → 执行」的可审计改谱闭环。

- **学习风格** — 把当前乐谱「学进」风格包：更新 genre/packs 的特征统计与指纹，让后续生成更贴近该样本。
  - 相关命令：`/learn-score`
  - 示例：`/learn-score chorale`
  - 效果：用当前曲更新 chorale 包，后续 /style chorale 更贴合。

- **体系层（非功能和声）** — 支持板腔 / 曲牌 / 拉格 / 十二音序列等体系，跳出功能和声范式。
  - 相关命令：`/system`
  - 示例：`/system 十二音序列`
  - 效果：按十二音序列技法生成，约束来自体系规则而非调性。

- **偏好与调性设置** — 用一组控件精确设定创作约束：调性/速度/拍号/小节/声部/赋格/风格。
  - 相关命令：`/key`、`/tempo`、`/meter`、`/bars`、`/voices`、`/fugue`、`/style`
  - 示例：`/key Am /tempo 90 /meter 3/4 /bars 24`
  - 效果：组合设定一首 A 小调、♩=90、3/4 拍、24 小节的创作约束。

- **导出 / 演示 / 会话** — 无 API 也能 /demo 看效果；/export 出谱；/new /clear /config 管理会话。
  - 相关命令：`/demo`、`/export`、`/new`、`/clear`、`/config`
  - 示例：`/demo /export`
  - 效果：先用演示曲看效果，再一键导出 MusicXML+MIDI。

### ▸ 设计理念

- **确定性内核与护城河** — 零训练数据、seed 固定可复现、规则校验、可审计——所有功能都建立在确定性内核 + 规则校验之上，不靠 LLM「凭空生成」。
  - 相关命令：`/skeleton`、`/interpolate`、`/groove`、`/refine`、`/import`、`/reverse-prompt`、`/replay`、`/brief-expand`、`/chords`
  - 示例：`任意 /chords 或 /skeleton 输入在固定 seed 下结果完全一致`
  - 效果：同一输入恒得同一输出，过程可被规则引擎逐步复算与审计。

## 二、命令速查（每个命令一个示例）

### ▸ 会话与帮助

- **`/help [命令或功能名]`** — 显示帮助文档。可带一个命令或功能名查看单项说明与示例；不带参数则输出完整命令+功能目录。/?, /help 等价。
  - 示例：`/help /chords`
  - 效果：输出 /chords 命令的语法、说明、示例与效果。

### ▸ 编辑与辅助

- **`/assist [on|off|style|inspire|harmony|status]`** — 音符级辅助作曲（程序化补全，不调 LLM）。开启后：Tab 下一音、Ctrl+Tab 本小节、Ctrl+Enter 全曲；1–5 选候选。
  - 示例：`/assist inspire jazzy`
  - 效果：切换辅助开关、绑定风格、灵感重排权重，或写入建议和声轨。

### ▸ 会话与帮助

- **`/new`** — 开始新曲会话：重置当前乐谱与创作状态，但保留调性/速度等偏好。
  - 示例：`/new /style 圆舞曲 快板轻盈`
  - 效果：清空当前曲目，生成新的 composition_id，并按 /style 设定基调。

- **`/clear`** — 清空对话历史与当前曲目状态，保留已设偏好（调性/速度/风格等）。
  - 示例：`/clear`
  - 效果：会话被清空，但 /key、/tempo、/style 等偏好仍在。

- **`/config`** — 显示当前配置与已设偏好（API 接入情况、调性、速度、风格、Groove 等）。
  - 示例：`/config`
  - 效果：返回一份配置摘要，便于确认创作环境。

### ▸ 演示与导出

- **`/demo`** — 已停用。新曲请用 /compose-grammar（例：/compose-grammar 奏鸣曲 小步舞曲）。
  - 示例：`/compose-grammar 奏鸣曲`
  - 效果：提示改用 /compose-grammar。

- **`/export`** — 导出当前乐谱为 MusicXML + MIDI（若开启 Groove，则 MIDI 含人性化处理）。
  - 示例：`/export`
  - 效果：在 scores/ 下写出当前曲目的 .xml 与 .mid。

### ▸ 分析与建议

- **`/analyze`** — 分析当前曲目：风格重叠率、16 维特征、声部/调性/曲式等，输出可读报告。
  - 示例：`/analyze`
  - 效果：返回风格向量比对与特征摘要，不含任何 LLM 主观评价。

- **`/advice`** — 给出修改建议（只分析、不改谱），待确认后用 /apply 执行。
  - 示例：`/advice`
  - 效果：输出针对当前曲的修改建议，状态记为「待执行」。

- **`/apply`** — 执行上一次 /advice 给出的建议，真正改写乐谱。
  - 示例：`/apply`
  - 效果：按建议重写当前乐谱；无建议或无色谱时给出提示。

### ▸ 偏好设置

- **`/key <调性>`** — 设置调性，例如 C / G / Am / Dm / bB。若已有乐谱则标记为移调待执行。
  - 示例：`/key Am`
  - 效果：调性 → Am（sharps=-3, minor）；有谱时提示可移调。

- **`/tempo <bpm>`** — 设置速度，范围 40–240。
  - 示例：`/tempo 72`
  - 效果：速度 → ♩=72。

- **`/meter <a/b>`** — 设置拍号，例如 4/4、3/4、6/8。
  - 示例：`/meter 3/4`
  - 效果：拍号 → 3/4。

- **`/bars <n>`** — 设置小节数，范围 4–32（影响新建/下一首生成；不改当前已打开的谱）。
  - 示例：`/bars 16`
  - 效果：小节数 → 16。

### ▸ 编辑类

- **`/addbars <n>`** — 在当前乐谱末尾追加 n 个空小节（1–32）。也可用菜单「文件 → 增加小节…」或编辑工具条「+小节」。
  - 示例：`/addbars 4`
  - 效果：谱末增加 4 个空小节，可直接点写。

- **`/addpart [piano|bass|violin|cello|…]`** — 为当前乐谱追加空声部。单声部用 piano/左手 可升为钢琴大谱表。也可用菜单「文件 → 添加声部…」或编辑工具条「+声部」。
  - 示例：`/addpart piano`
  - 效果：在旋律旁加上 LH 低音谱表（花括号大谱表）。

- **`/accomp [bass|block|broken|alberti]`** — 根据旋律声部写入配乐（确定性）。无低音声部时自动添加。也可用菜单「文件 → 设置配乐…」或编辑工具条「配乐」。
  - 示例：`/accomp alberti`
  - 效果：低音声部写入阿尔贝蒂低音伴奏。

### ▸ 偏好设置

- **`/voices 0|2|3|4`** — 设置声部数。0=由风格自动推导，2/3/4 为固定声部数。
  - 示例：`/voices 3`
  - 效果：声部数 → 3（0=自动）。

- **`/style <风格名>`** — 设定/绑定风格包。风格名写命令后，创作描述写后面或下一句。输入 /style 会弹出可选列表——只列「学过」的包（有 grammar.yaml，见右侧检查器「风格包」下拉）；未学过的包不在候选里。
  - 示例：`/style 众赞歌 庄重匀净`
  - 效果：风格 → 众赞歌（并绑定 genre 包）；「庄重匀净」记入创作描述。

### ▸ 风格学习

- **`/learn-grammar [chorale|folk|jazz|pop|madrigal|sonata|strings|symphony|chopin|all]`** — 从乐谱语料学习可解释作曲语法，蒸馏成带编号的规则脚本 grammar.yaml 与中文说明 grammar.md，并报告留出集困惑度。chorale 与 leadsheet 两套流水线共用 score_learning.learn_core：Witten-Bell 回退、只删低频上下文的剪枝（留出困惑度变差则自动回退）、k-means++ 多次重启。不带参数 = music21 自带的 350 首巴赫众赞歌（逐拍和弦识别 → 乐句/终止切分 → 句终规划、终止公式、按“距终止拍数”条件化的和声转移、旋律轮廓、声部配置）。folk = Nottingham 民谣（吉格/里尔/角笛舞/华尔兹）、jazz = Weimar 爵士独奏（摇摆/比波普/酷派/硬波普/后波普/传统）、pop = Billboard 流行歌、madrigal = 蒙特威尔第牧歌：按子风格学曲式（AABB/AABA/ABAB…）、段落终止公式、按段内位置条件化的和弦转移、小节节奏模板或拍内节奏单元链、旋律音程/和弦音比例/音域与硬规则 R01–R10（复杂度预算随声部/配器自动伸缩）。sonata = KernScores 贝多芬/莫扎特/海顿钢琴奏鸣曲、strings = 贝多芬/莫扎特/海顿弦乐四重奏、symphony = 海顿《伦敦交响曲》第 99–104 号 + CCARH 贝多芬九部交响曲（MuseData） + S3 莫扎特第 41 / 贝多芬第 9（只读弦乐/全谱分析和声）、chopin = 肖邦玛祖卡：乐谱没有和弦标注，分析器自己识别和声——逐拍（4/4 每半小节）按音高证据给候选和弦打分 → 维特比平滑（强拍换和弦代价低）→ 24 个调上的维特比找局部调，≥8 小节的调区各自成段、和弦按局部调记级数；词表只留占比 ≥1% 且有古典和声功能的和弦（调内、副属、借用、那不勒斯），转移概率与整体频率按 1:3 插值以抵消识别噪声；子风格按拍号分（快板 4/4、小步舞曲 3/4、二拍子 2/4、复拍子 6/8）。all = 全部。说明：/learn-score 是把当前曲学进风格包指纹；/learn-grammar 才是可解释规则学习。
  - 示例：`/learn-grammar jazz`
  - 效果：写出 skills/composition/genre/packs/<风格>/grammar.yaml / grammar.md 并列出各子风格的曲子数、曲式与困惑度（含 prune_kept / bigram_coverage）。

- **`/compose-grammar [风格 子风格] [major|minor] [小节数] [弱起|强拍起] [乐器] [seed=…] [t=温度]`** — 只读学到的规则脚本、确定性地作曲（不调 LLM），同一 seed 逐音符复现。不带风格词 = SATB 巴赫众赞歌：句终规划 → 终止公式 → 和声+女高音联合搜索 → 低音 → 内声部 → 经过音；平行五八度/交叉/导音/七音等硬规则 0 违例，每拍可追溯到规则编号（H 和声 / C 终止 / F 句终规划 / M 旋律轮廓）。弱起（pickup）= 一拍弱起小节 + 指定小节数，句终落第 3 拍并加延长；不指定时按语料比例（约 72% 弱起）抽签。带风格词（民谣/jig/reel/hornpipe/waltz、爵士/swing/bebop/cool/hardbop/postbop/traditional、流行、牧歌）= 旋律 + 钢琴伴奏：按学到的曲式分段（重复段逐音符再现）→ 每段和弦进行（终止公式 + 位置条件转移）→ 节奏（小节模板或节奏单元链）→ 旋律动态规划 → 按风格写伴奏（民谣“嘭-嚓”、爵士走动低音 + 三七和弦、流行分解律动、牧歌持续和弦）；R01–R10 硬规则（强拍非和弦音解决、跳进上限、音域、主和弦收尾、语料未见的和弦转移、三声部之间无平行五八度、节奏只用学到的模板、同一和弦连续小节上限）0 违例。小节数取 8 的倍数（默认 32，牧歌 24）；乐器可写 violin/flute/trumpet/clarinet/voice/soprano 或中文名；调号/速度没指定时用风格默认。奏鸣曲（快板/小步舞曲/二拍子/复拍子）与肖邦玛祖卡 = 钢琴独奏：右手旋律，左手按拍号写阿尔贝蒂低音（4/4、2/4）、分解三和弦（6/8）或低音-和弦-和弦（3/4），每个音型候选都逐起音检查与旋律无平行五八度；四重奏 = 第一小提琴旋律、第二小提琴 + 中提琴双音配位同音反复（3/4 第一拍休止）、大提琴低音，四个声部两两无平行五八度。交响曲（海顿 / 莫扎特 / 贝多芬 / symphony：快板/小步舞曲/二拍子/复拍子）= 古典双管缩编总谱：长笛、双簧管、圆号、大管、定音鼓 + 弦乐四部；弦乐组按四重奏织体全程演奏，偶数段与末段全奏——长笛高八度/双簧管同度加倍旋律、大管加倍大提琴、圆号持续主/属音（避开与各声部的平行）、定音鼓在主/属和弦小节第一拍击奏。不用斜杠也行：直接说「作一曲小步舞曲」「写一首海顿交响曲小步舞曲」「来一首忧伤的玛祖卡」「写一首巴赫众赞歌」「做一首交响」——关键词或 LLM 路由到 /compose-grammar 后做确定性作曲（不再走 Planner / translator 写新曲）。识别不出已学风格时会提示用法。只说「小步舞曲」= 钢琴奏鸣曲小步舞曲，带「弦乐/四重奏」= 四重奏，带「交响/管弦」= 交响曲。
  - 示例：`/compose-grammar 爵士 bebop 32 seed=1`
  - 效果：众赞歌：四部谱面 + 每句的终止目标与和声进行；其他风格：旋律 + 钢琴大谱表 / 四重奏 / 管弦乐总谱，回复里列出曲式与每段的终止公式和和弦。

## 四、对位法规则（权威）

> 凡涉及对位 / 一比一 / species，均遵守下列规则。单项详情：`/help 对位法`。

## 对位法规则（第一类二声部 · 权威）

凡用户请求涉及**对位 / 一比一 / 第一类 / species / note-against-note**（且未明确要求赋格）时，
一律按本规则执行。对位 ≠ 赋格：未点名赋格/卡农/创意曲时不要走赋格。

### 谱面与织体
1. **钢琴大谱表**：上方高音谱表、下方低音谱表（RH/LH，`piano`×2）。
2. **一比一（第一类）**：每小节每声部**恰好一个全音符**；禁止一小节多音或空小节。
3. 默认 8–16 小节；调性清晰，开头与结尾同调。

### 纵向音程
4. **开头**：低音为主音；高音落在主三和弦；可用同度/三/六/五/八度。
5. **中间小节**：以 **3 度、6 度** 为主；允许经**反向**到达的 **5 度、8 度**；**禁止纯 4 度**（含复音程归约后的纯四）。
6. **结尾**：两声部成**八度**；须**反向**到达（两声部都运动，禁止同向或一静一动）。

### 终止式（硬）
7. 倒数第二→末小节：
   - 高音：**导音 → 主音**（上行半音/级进 +1）
   - 低音：**二级 → 主音**（下行级进 −2）

### 声部独立性与进行
8. **禁止两声部同时跳进**（一侧跳进时另一侧必须级进）。
9. **跳进后须反向级进**（跳进后的下一音须朝反方向级进收回）。
10. **相邻小节同声部不得同音高**（禁止原地重复）。
11. **限制连续平行 3/6 度**（连续同行同度级平行 ≤ 2 步）；**反向进行占比 ≥ 45%**。
12. **高低声部最高音须错开小节**（不可同时到达各自峰值）。
13. **低音以级进为主**（级进比 ≥ 60%）。
14. **开头与结尾音域一致**：低音首尾同音高；高音首尾同一八度音域。

### 流程约定
15. **确定性写谱**：意图由 Planner 识别（`species: true`）后由内核生成并校验；不把音符交给 LLM。
16. **每次作曲重新随机 seed**（可复现调试时可显式固定 seed）。
17. **禁止**在仅「对位」请求下自动插入赋格段。
18. **根据当前乐谱**：提示「根据/基于当前打开的乐谱写 1:1 对位」时，从当前谱每小节抽一音作定旋律，另一声部按本规则生成（定旋律侧旋律约束可微调）。

> 实现与校验：`music_score/two_part_species.py`（`validate_two_part_species`）。
> 聊天内查阅：`/help 对位法` 或 `/help 二声部对位`。
