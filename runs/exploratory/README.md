# 探索性材料（不属于论文证据）

本目录存放开发过程中的探索性人工评测材料，**未进入 ESWA 论文的任何结论**，也不作为论文的补充材料。

- `blind_review/`：2026-10-05 的 20 首生成质量盲听（12 首机器、8 首巴赫）。只有一位听众、一轮，没有预注册协议。结果是听众以 18/20 的准确率分辨出机器作品，说明当前生成器在听感上仍可辨识；这一结果只用于内部改进方向，论文不声称听感质量。`_答案_评审后开封.json` 是该轮的答案文件，该轮评审已结束。
- `人工评审材料_2026-10-05.zip`：同日发给评审人的打包材料（含上面的盲听包，以及当时 35 条待定终止式的旧版评审表；终止式评审的现行版本见 `docs/cadence_review/`）。

论文使用的专家评审材料在 `docs/cadence_review/`（终止式裁定）与 `docs/expert_review/`（检查器裁定），其答案键不入库。
