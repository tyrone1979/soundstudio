# 专业提示词 ·《苍穹》单乐章交响曲（奏鸣曲式）

> 用法：整段复制粘贴到作曲对话框发送即可。无需 `/style`，无需其它命令。

```
【作品】为完整交响乐团而作的单乐章交响曲《苍穹》，C 大调，4/4，共 32 小节，
奏鸣曲式：引子—主部—副部—展开部—再现部—尾声。

【编制】交响乐团（双管木管 + 四声部铜管 + 定音鼓 + 完整弦乐组）；旋律由木管（长笛）
与弦乐（第一小提琴）承担，低声部由大提琴与低音提琴承担。旋律音区最高到 high，
不要用 very_high（会超出木管音域）；高潮靠加厚而非拔高音区。

【速度】全曲必须按此速度阶梯：引子 ♩=84 → 主部 ♩=104 → 副部 ♩=126 →
展开部 ♩=132 → 再现部 ♩=118 → 尾声 ♩=100（相邻段变化均 ≤±25%，平滑衔接）。
六段小节数之和必须等于 32。

【第 1 段 · 引子】4 小节 · Maestoso ♩=84 · ff · C 大调。庄严的号角式宣告，
只用主、属功能（I–V），柱式和弦叠加长音低音，营造开阔的舞台感。

【第 2 段 · 主部主题】6 小节 · Allegro con brio ♩=104 · f · C 大调。快板主部，
旋律 driving、contour=arch，和声 I–vi–IV–V7。呈示全曲核心动机：属音起、级数
5–5–1–3 的四音动机（四分–八分–四分–四分），每句首小节呈现并作二度模进；
低声部用八度脉冲推进。

【第 3 段 · 副部主题】5 小节 · Allegro ♩=126 · mf · 转 G 大调（+1 升号）。
歌唱性副题，旋律 flowing、register=high、contour=arch，和声按新调 I–V7–I–IV，
伴奏改为分解和弦，力度柔和下来，与刚健的主部形成抒情对照。

【第 4 段 · 展开部】8 小节 · Agitato ♩=132 · ff · 转 a 小调（关系小调，不换调号，
mode=minor）。冲突与不安：旋律 fragmented、register=high；和声 i–VI–iv–V7，
并偶用 bII 那不勒斯和弦增添色彩；低声部改用半音下行（chromatic_descent）。
本段为全曲戏剧高潮，用 thicken 对旋律八度加厚。

【第 5 段 · 再现部】5 小节 · Tempo I ♩=118 · f · 回到 C 大调。主部动机以原调
再现（可作节奏变化或倒影），和声 I–IV–V7–I，织体回到明确的调性肯定。

【第 6 段 · 尾声】4 小节 · Maestoso ♩=100 · ff · C 大调。全奏收束，以 V7–I 的
完满终止结束，末两小节为主和弦长音（显式终止式）。

【不要】不要赋格，不要复调模仿，不要卡农。
```
