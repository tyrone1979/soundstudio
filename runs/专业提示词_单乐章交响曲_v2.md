# 专业提示词 ·《苍穹》单乐章交响曲（奏鸣曲式）· v2

> v1 → v2 的修改原因见文末「v2 改了什么」。
> 用法：整段复制粘贴到作曲对话框发送即可。无需 `/style`，无需其它命令。

```
【作品】为完整交响乐团而作的单乐章交响曲《苍穹》，C 大调，4/4，共 32 小节，
奏鸣曲式：引子—主部—副部—展开部—再现部—尾声。

【编制】交响乐团（双管木管 + 四声部铜管 + 定音鼓 + 完整弦乐组）；旋律由长笛
与第一小提琴交替承担，低声部由大提琴与低音提琴承担。旋律音区最高到 high，
不要用 very_high（会超出木管音域）；高潮靠加厚而非拔高音区。

【速度】全曲必须按此速度阶梯：引子 ♩=84 → 主部 ♩=104 → 副部 ♩=126 →
展开部 ♩=132 → 再现部 ♩=118 → 尾声 ♩=100（相邻段变化均 ≤±25%，平滑衔接）。
六段小节数之和必须等于 32。

【旋律总则｜必须遵守】
1. 六段的旋律形态必须互相区分，不许雷同：rhythm 依次用 sparse / driving /
   flowing / fragmented / flowing / driving，contour 也逐段不同。
2. 再现部不许把主部原样照搬：换一个节奏化的 motif（如附点四分起句），
   或干脆不给 motif，避免与主部逐音相同。
3. 全曲不要赋格式动机变形（倒影/逆行/增时/减时/加花），不要复调模仿，不要卡农。
   请在 cadence 之后、finalize 之前显式调用 narrative(appearances=false)，
   保证旋律严格保持你写下的形态。
4. 每段旋律只使用本段调内音（转调后按新调），不得出现调外音；
   唯一例外是展开部那一个 bII 那不勒斯和弦所在小节。
5. 任何段落都不许用「整小节一个音」的写法（尾部终止式除外）。

【第 1 段 · 引子】4 小节 · Maestoso ♩=84 · ff · C 大调。庄严的号角式宣告，
只用主、属功能（I–V），柱式和弦叠加长音低音，营造开阔的舞台感。
旋律 rhythm=sparse、register=mid、contour=ascending。

【第 2 段 · 主部主题】6 小节 · Allegro con brio ♩=104 · f · C 大调。快板主部，
旋律 driving、contour=arch，和声 I–vi–IV–V7。呈示全曲核心动机：属音起、级数
5–5–1–3 的四音动机（四分–八分–四分–四分），每句首小节呈现并作二度模进；
低声部用八度脉冲推进。

【第 3 段 · 副部主题】5 小节 · Allegro ♩=126 · mf · 转 G 大调（+1 升号）。
歌唱性副题，旋律 flowing、register=high、contour=arch，和声按新调 I–V7–I–IV，
伴奏改为分解和弦，力度柔和下来，与刚健的主部形成抒情对照。

【第 4 段 · 展开部】8 小节 · Agitato ♩=132 · ff · 转 a 小调（关系小调，不换调号，
mode=minor）。冲突与不安：旋律 fragmented、register=high、contour=wave；
和声 i–VI–iv–V7，并偶用 bII 那不勒斯和弦增添色彩；低声部改用半音下行
（chromatic_descent）。本段为全曲戏剧高潮，用 thicken 对旋律八度加厚。

【第 5 段 · 再现部】5 小节 · Tempo I ♩=118 · f · 回到 C 大调。主部素材的**变化**
再现：旋律用 flowing + contour=descending（与主部的 driving+arch 形成对比），
motif 必须换节奏（建议附点四分起句 [[5,"dotted_quarter"],[1,"eighth"],[3,"half"]]）；
和声 I–IV–V7–I，织体回到明确的调性肯定。

【第 6 段 · 尾声】4 小节 · Maestoso ♩=100 · ff · C 大调。全奏**饱满**收束：
前两小节旋律要有推进力（rhythm=driving、contour=ascending，**绝不要 sparse、
不要整小节长音**），以 V7–I 推进；最后两小节才是主和弦长音（用 cadence bars=2）。

【不要】不要赋格，不要复调模仿，不要卡农，不要动机变形，不要把尾声写成整小节长音。
```

## v2 改了什么（对照 v1）

| # | v1 的写法 | v2 的写法 | 为什么 |
|---|---|---|---|
| 1 | 尾声只写「全奏收束…末两小节为主和弦长音」 | 明确「前两小节 rhythm=driving、**绝不要 sparse / 整小节长音**；最后两小节才用 cadence」 | v1 被译成 `rhythm=sparse`，4 小节只剩 6–10 个音，旋律近乎消失（**这是「后面一段特别单一」的主因**） |
| 2 | 再现部「可作节奏变化或倒影」 | 明确「必须换节奏 motif（给示例）；不要与主部逐音相同」 | `melody(motif=…)` 的首小节是逐音确定的，两段同一 motif 会让再现部首小节与主部**完全相同**（听感像复制） |
| 3 | 【不要】只说了「不要赋格/复调模仿/卡农」 | 增加「不要动机变形」+ 显式要求 `narrative(appearances=false)` | 内核 `finalize` 会自动补 `narrative` 层，默认用倒影/逆行/增时/减时/加花**重写高音声部**（第 11/16/21/26/31 小节）——这正是「不要」失效的原因 |
| 4 | 未提「调内音」 | 新增「每段只用本段调内音，唯一例外是展开部 bII 小节」 | 动机变形算子按半音运算，曾写出 Eb/Db/Gb/Ab 等调外音（内核侧已同时修复） |
| 5 | 未要求段落间形态对比 | 新增「旋律总则 1」：六段 rhythm/contour 必须逐段不同 | v1 六段里三段都是 `flowing/arch`，织体雷同 |
